# LinkPage

LinkPage is a self-hosted link-in-bio app built with Go and SQLite. It can run as a simple single-binary app, or as a declarative service with a seed file and NixOS module.

## What you get

- Clean public page with responsive editorial styling
- Built-in admin panel protected with Basic Auth
- Optional declarative seed mode for infrastructure-managed links
- SQLite by default, no separate database service required
- Nix flake package and NixOS module for multi-instance deployments
- GitHub release artifacts and Docker images
